Doing this accessibility audit completely changed how I look at building websites. I used to just focus on making things look clean, but running the site through the WAVE tool made me realize how much invisible stuff can completely break the experience for someone else. For example, WAVE flagged an empty label error on the contact form input, which basically meant a screen reader wouldn't tell a user what to type there. It also hit me with a low-contrast alert on the main navigation links because the light gray text on the white background was way too hard to read. Plus, WAVE caught a missing alternative text error on the main profile picture image element, meaning anyone who can't see the image would just miss out on what it is entirely. Going into the linked code to fix these issues—by adding proper label text, darkening the nav colors, and throwing in descriptive alt tags—made me realize that accessibility isn't just an extra chore at the end. It's a fundamental part of coding that forces you to write cleaner, better structure from the start, and seeing WAVE give it a completely clean report afterward felt awesome.
